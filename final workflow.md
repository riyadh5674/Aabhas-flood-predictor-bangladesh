## 0. How to work with this document

### 0.1 Ordering rule (D10, carried)

The **body `Phase N` sequence runs in numeric order and is the driver**. The stage checklist
(§5) is a cross-reference, not the driver. Every report cites *both*, e.g.
*"Phase 21 / stage 36"*.

### 0.2 Definition of done — every phase

A phase is complete only when all four exist and agree:

1. **Code** — `scripts/*.py` and/or `notebooks/NN_*.ipynb` (notebooks are generated by
   `scripts/build_phaseN_notebook.py` and executed with the `flood-predictor` kernel).
2. **Run record** — a log file (`scripts/phaseN_run.log` or notebook output) with exit code,
   wall-clock time and seed.
3. **Report** — `reports/phaseN_<topic>.md` with the numbers, the failures and the warnings;
   a stale or contradicted number is a defect, not a footnote.
4. **Checklist + phase0 update** — the stage row in §5 flipped to DONE with the evidence.

New artifacts must state the SHA-256 of `data/processed/experimental_dataset.csv`
(`a6748529083fcdce…`) or re-verify it: **the experimental table is immutable.**

### 0.3 The experiment contract (binding, inherited from Phase 0/15/16)

| Item | Contract |
| --- | --- |
| Research question | *What is the probability of flooding at a particular location within the next 24/48/72 hours?* — a probabilistic lead-time forecast, not a classifier, not a susceptibility map |
| Prediction unit | one FFWC station × one issue day (200,665 station-days, 133 stations) |
| Issue instant | 24:00 UTC of day `t`; features use only day `t` and earlier |
| Labels | `label_24h/48h/72h` = any observed reading in `(t, t+h]` ≥ official FFWC danger level; **missing stays NaN, never 0**; `obs_days_*` are label-window columns → banned as features |
| Features | 62-column FULL / 35-column LINEAR / 10-column SELECTED sets (`feature_sets.json`); banned columns asserted absent |
| Splits (`split_assignments.csv`) | train ≤ 2021 (61,991) / val 2022 (17,538) / test 2023+ (101,174, frozen); 7-day embargo; 5 station-disjoint spatial folds with fold 0 = 26 stations held out of every training set; `station_holdout` rows excluded from train/val; season column (JJAS vs rest) |
| Protocols | **P1** temporal primary · **P2** rolling origin per year · **P3** spatial CV (4 folds) · plus monsoon/non-monsoon cells and test buckets `trained / unseen / new_network` |
| Metrics | **PR-AUC primary** (R4); ROC-AUC secondary; recall/precision/F1/specificity at **train-derived thresholds**; Brier + ECE + reliability; macro **and** micro per-station; station-bootstrap 95 % CI (100 reps) on test; **accuracy banned as a headline** (Phase 16 §10) |
| Never pool | years, seasons, station buckets or horizons (D8, R1, D1) |
| Reference bar | **D7 persistence** — `wl_pct_danger` alone — reported next to every model (D7) |
| Imbalance | ratios 9.4:1 train → 18.6:1 val → **70:1** test at 24 h; resampling / class weighting **inside the training process only**; thresholds are train-derived and period-specific (Phase 16 §10) |
| Test discipline | test is scored **after** a phase's decisions are frozen; every test read is logged (who, when, which models) and enters a `*_test_metrics.csv`; test never selects anything |
| Seed | 20261008 unless a phase states otherwise |

### 0.4 Decisions and risks carried forward

D1 monsoon = **JJAS** · D2 all three horizons reported equally · D5 label drift must be
explained, never pooled · D6 missingness may be informative · D7 persistence bar · D8
rolling-origin, per-year, macro+micro · D9 water-level spike filter on read · D10 phase order
rule.

R1 base-rate drift (16.8 % 2017 → 1.19 % 2023) · R2 tidal-station dominance (re-measured
73.2 % Mongla, W-R2) · R3 zero-positive stations (re-measured 14, W-R3) · R4 class imbalance
· R5 rainfall is NASA POWER reanalysis, not observed · R6 2018 archive gap, never
interpolated · R7 growing station network (85 → 133) · R8 soil/landcover data absent.

## Phase 19 — Sequence construction & validation · stage 33

Prove the sequences are scientifically valid **before** any LSTM/GRU/TCN is trained. This is
the DL counterpart of the Phase 13 leakage audit.

1. **Chronological order** within each station — asserted, never assumed.
2. **Continuity check:** report the distribution of calendar gaps inside every window. The
   2018 archive gap (R6) and station outages mean windows are *not* uniformly consecutive.
3. **Missing-timestep policy (must be written down):** candidate rules — interpolation only
   where scientifically justified, forward-fill with an age limit, a missingness **mask
   channel**, minimum-observed-days per window, or whole-window rejection. Pick one rule on
   evidence, apply it identically everywhere, and report how many samples each rule drops.
4. **No station mixing:** a window never contains two stations.
5. **No forward reach:** every timestep in a window is ≤ `t`. Windows may legitimately reach
   *backwards* across a split boundary (history at issue time is legal); they may never
   reach forward into the label window or across the embargo into a future split.
6. **Label alignment test:** for a random sample of 100 windows, recompute the label from the
   raw readings and assert equality with `label_*` — the same windows, the same day `t`.
7. **Split/holdout inheritance:** windows inherit the split, spatial fold, holdout and
   season of their anchor day `t`; a holdout station's windows can never appear in training.

**Deliverable:** `notebooks/09_sequence_validation.ipynb` with numbered checks (S-ids), all
green, plus `reports/phase19_sequences.md`. **DoD:** every check passes; the missing-timestep
policy is stated as a rule with numbers (samples kept/dropped per `L`).

## Phase 33 — Final model selection · stage 57 · **DONE**

Multi-criteria, written as a scorecard, not "highest accuracy wins":

| criterion | weight/role |
| --- | --- |
| PR-AUC vs D7 bar (per year, per season, per bucket) | primary |
| flood recall / missed-flood count at the chosen threshold | co-primary (FN ≫ FP) |
| calibration (Brier/ECE, post-Phase 28) | gate — must be usable for risk bands |
| temporal generalisation (P2, worst year) | strong evidence |
| spatial generalisation (P3, `unseen`, `new_network`) | strong evidence |
| robustness + ablation consistency | evidence |
| interpretability (SHAP availability, family transparency) | tie-breaker |
| train/inference cost, model size, hardware feasibility | tie-breaker |

## 7. The six priorities (unchanged, still binding)

1. Correct flood-label definition — already fixed, never weakened.
2. Leakage-free temporal/spatial experimental design — already fixed.
3. Meaningful feature engineering based on flood science.
4. Evaluation focused on recall, PR-AUC, calibration and false negatives.
5. Explainable, location-aware risk prediction.
6. Only then: map, automatic data acquisition and early-warning application.

And the standing warning from the proposal: **an apparently excellent model may simply be
benefiting from an easy split or leakage** — that is what Phases 13, 15, 19, 24, 27 and the
definition-of-done checks exist to prevent.
